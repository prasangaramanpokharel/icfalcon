# Chain Fusion Architecture (Bitcoin & EVM Direct Integration)

Chain Fusion enables canisters to directly sign transactions and query state on foreign blockchains (Bitcoin, Ethereum, Polygon, Arbitrum) without bridges or third-party intermediaries.

---

## 1. Direct Bitcoin Integration (`ckBTC`)

Canisters can query the Bitcoin UTXO set directly through the Bitcoin canister on ICP:
- **Zero Bridge Risk**: Threshold ECDSA keys generated by the ICP consensus threshold network hold funds directly on the Bitcoin mainnet.
- **`ckBTC` (Chain-Key Bitcoin)**: 1:1 backed by real BTC held by the canister. Transfer fees are microscopic (<$0.01) with 1-2 second finality.

---

## 2. EVM Integration via RPC & Threshold ECDSA

Canisters can sign Ethereum transactions using `ecdsa_sign`:
1. Canister derives a unique Ethereum address from its own Principal.
2. Submits queries to Ethereum via HTTPS Outcalls to standard RPC providers (Infura, Alchemy, Cloudflare).
3. Signs and broadcasts raw EVM transactions with threshold ECDSA signatures.
